# Adaptive Smart Traffic Light Controller using LPC1768 ARM Cortex-M3

## Overview
An adaptive smart traffic light controller developed using the LPC1768 ARM Cortex-M3 microcontroller and IR sensors for real-time traffic density detection and signal management.

## Features
- Real-time vehicle detection using IR sensors
- Adaptive traffic signal timing
- Priority-based lane management
- GPIO interfacing and register-level hardware control
- Embedded C implementation on LPC1768

## Technologies Used
- Embedded C
- LPC1768 ARM Cortex-M3
- Keil uVision
- IR Sensors

## System Functionality
The system dynamically adjusts traffic signal duration based on vehicle density detected on different lanes, reducing unnecessary waiting time and improving traffic flow efficiency.
